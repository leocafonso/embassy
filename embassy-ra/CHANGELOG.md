### Added

#### HAL crate

- Initial `embassy-ra` crate for Renesas RA microcontrollers.
- `build.rs` generates from chip metadata at compile time:
  - `memory.x` — linker script with FLASH, RAM, and option-byte regions per chip variant.
  - `peripherals.rs` — type-safe peripheral singleton wrappers.
  - `irq_bindings.rs` — ICU IELSR slot assignments for peripheral events.
  - `option_bytes.rs` — OFS0/OFS1 statics placed in the correct flash sections; HOCO frequency selected via the `hoco-*` Cargo feature.
- Chip variant selected via a single Cargo feature flag (e.g. `r7fa6e2bb3cfm`).

#### Clock initialization (`system` module)

Two clock families are fully implemented and hardware-validated:

- **`v1` — RA2 family** (RA2E1, RA2E2, RA2L1, RA2A1, …)
  - Clock sources: HOCO (24/32/48/64 MHz), MOCO, LOCO, MOSC, SubOsc
  - No PLL. Max ICLK: 48 MHz, PCLKB: 32 MHz, PCLKD: 64 MHz.
  - HOCO frequency: `hoco-24mhz` | `hoco-32mhz` | `hoco-48mhz` | `hoco-64mhz`
  - Configurable dividers: ICLK, PCLKB, PCLKD, FCLK.

- **`v4` — RA4M2+, RA6M4/M5, RA6E1/E2, RA6T2/T3**
  - Clock sources: HOCO (16/18/20 MHz), MOCO, LOCO, MOSC, SubOsc, PLL.
  - PLL: 16-bit PLLCCR — `PllV4Config { source, input_div, mul }`. No hardware PLODIV; VCO feeds SCKDIVCR directly.
  - Max ICLK: 200 MHz (RA6), 100 MHz (RA4 sub-family). Max PCLKA: 100 MHz, PCLKB: 50 MHz.
  - HOCO frequency: `hoco-16mhz` | `hoco-18mhz` | `hoco-20mhz`
  - Configurable dividers: ICLK, PCLKA, PCLKB, PCLKC, PCLKD, FCLK, BCLK.
  - Flash wait states (FCACHE.FLWT) set automatically before raising ICLK.

All other RA families (RA0, RA4M1, RA6M1–M3, RA8, …) are not yet supported;
selecting their chip feature will produce a compile-time error.

#### MSTP — peripheral clock gating

- `mstp::enable_clock` / `mstp::disable_clock` gate module-stop clocks before peripheral use.
- Dispatches MSTPCRA writes to the MSTP peripheral (RA6 TrustZone chips) or SYSC (RA2 and RA6 non-TZ).
- Called automatically by peripheral drivers; not typically needed in user code.

#### ICU interrupt model

- Dynamic IELSR slot allocation: `build.rs` assigns ICU slots to peripheral events at compile time from chip metadata.
- `bind_interrupts!` macro wires per-peripheral event handlers to their allocated slots.
- RA2-specific grouped-interrupt slot constraints respected automatically.

#### GPIO (`gpio` feature)

- `Input`, `Output`, and `Flex` pin types backed by the RA PORT/PFS register model.
- Implements `embedded-hal` 1.0 `InputPin`, `OutputPin`, and `StatefulOutputPin` traits.
- Pin singletons generated by `build.rs` from chip pin metadata (e.g. `peripherals::P207`).

#### AGT time driver (`time-driver-agt0` feature)

- Embassy `TimeDriver` backed by AGT0 (Asynchronous General Timer channel 0).
- Supports 16-bit AGT (RA2 family, `agt_counter_16bit` cfg) and 32-bit AGT (RA6 family, `agt_counter_32bit`), selected automatically from chip metadata.
- Integrates with `embassy-time`; use `Timer::after_*` and `Instant::now()` as usual.

#### Examples

- `examples/ra6e2` — blink for EK-RA6E2 (R7FA6E2BB3CFM, Cortex-M33 TrustZone, up to 200 MHz).
- `examples/ra2e1` — blink for EK-RA2E1 (R7FA2E1A9, Cortex-M23, up to 48 MHz).
- Both use GPIO output, AGT0 time driver, and defmt RTT logging via probe-rs.
- Binaries in `src/bin/`, Rust edition 2024, `lto = true`, `opt-level = "s"` (~8 KB flash).
